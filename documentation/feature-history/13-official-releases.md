# Official Releases

  - `v1.0.0`: Initial production release with full offline tracking, rotary controls, template management, sync protocol, Health Connect, and standalone APK binaries.
  - `v1.1.0`: Standalone Phone Workout Tracking, Bidirectional Session History Sync, SQLCipher AES-256 DB Encryption, Security & Privacy Hardening, and Clamped Validation.
  - `v1.2.0`: Local Storage Backup & Restore with SAF, GZip/JSON export, SHA-256 integrity verification, automated periodic backup worker, and settings UI.
  - `v1.2.1`: Patch release fixing the SQLCipher 4.17.0 `UnsatisfiedLinkError` startup crash via explicit `System.loadLibrary("sqlcipher")` in the database builder (code 4).
  - `v1.3.0`: Minor feature release delivering full Workout History Editing & Deletion on Mobile (Issue #20), Wear OS Tracking UX Enhancements with Workout Pause/Resume, Configurable Rest Timer, and in-workout set editing (Issue #21), and Companion Connection Status & Manual Sync Configuration (US 5.3 / Issue #22) (code 5).
  - `v1.3.1`: Patch release unifying `applicationId = "com.lockerlift"` across `:mobile` and `:wear` modules and registering modern `wear_capabilities.xml` manifest declarations, fixing Google Play Services Wearable Data Layer companion discovery and sync isolation (code 6).
  - `v1.4.0`: Minor feature release delivering Intuitive Mobile Live Workout Tracking with Set Table & Previous Performance Comparison, Live In-Workout Set Editing & Deletion, Equipment Swapping preserving logged sets, Station Reordering, Smart Next-Station Flow, and Wear OS Always-In-Foreground Tracking & Wake Behavior (code 7).
  - `v1.5.0`: Minor feature release delivering Phone-Initiated Pull-to-Refresh Synchronization with Wear OS Wake-Up (US 5.4 / Issue #23), Bidirectional Sync Resiliency Hardening, and Wear OS Workout Flow UX Enhancement with "Übung beenden" ("Finish Exercise") action (code 8).
  - `v1.5.1`: Patch release hardening the Wearable Data Layer sync engine against stalls and race conditions, and redesigning mobile weight stepper controls into a 2-row layout with dynamic machine increment adaptation and anti-wrapping safeguards (code 9).
  - `v1.6.0`: Minor feature release delivering Brand Redesign with Minimalist AI Vector Mark & Native App Icons (Adaptive & Round) across Mobile and Wear OS, In-Memory End-to-End Synchronization Test Suite with On-Demand CI Trigger, and shared SyncIngestionEngine refactoring (code 10).
  - `v1.7.3`: Patch release delivering comprehensive Sync Reliability Hardening — 4 critical fixes (master data queue routing via DataClient, 15-min periodic sync safety net, tombstone on local deletion preventing zombie resurrection, orphaned session recovery on app startup), 7 high-priority fixes (missing `/workout_nack` manifest filters, watch-to-phone master data pull, strict capability matching, transactional ingestion, GlobalScope elimination, master data queue dedup, dead-letter after 10 retries), and 6 medium/low fixes (tombstone cleanup, payload versioning, exponential backoff, dead code removal). Includes 37 new tests (30 unit + 6 E2E + 1 DAO contract) (code 13).
  - `v1.9.0`: Minor feature release delivering the Wear Compose Material 3 migration (round-screen-optimized buttons, cards, and compact controls), dynamic color on watch and phone (Material You dark scheme on Android 12+, static LockerLift brand palette as fallback), theme-following wear buttons after removing leftover Wear Material 1 components, a four-tab bottom navigation on mobile, and the toolchain upgrade to Gradle 9.6.0 / AGP 9.4.1 / Kotlin 2.2.10 / KSP 2.3.6 / Room 2.8.5 with aligned CI pipelines. Published as unsigned APKs (code 16).
  - `v1.9.1`: Patch release fixing the two mobile navigation regressions introduced with the four-tab bottom navigation in v1.9.0 — the settings screen trap (no exit via bottom nav or system back) and the history Sessions/Insights sub-tab bar rendered behind the status bar, which made the Insights dashboard unreachable (code 17).
  - `v1.10.0`: Minor feature release delivering crash-safe durable workout sessions (per-change snapshot persistence in the encrypted database, exact resume after ambient-mode kills on Wear OS and mobile), the MVVM presentation-layer refactoring with StateFlow-driven ViewModels, the move of pure workout logic into `:core:model` (`WorkoutLogic`), Room database v3 with clean 2→3 migration, and 23 new unit tests (code 18).
  - `v1.11.0`: Minor feature release delivering per-machine weight units with unit-specific increments kg/lbs (Issue #37), muscle group autocomplete in machine forms (Issue #36), soft-delete for machines and templates with swipe-to-delete and active-workout protection (Issue #40), the open-source license page via AboutLibraries with license-URL fallback, and the Wear OS finish-workout confirmation with relocated settings button (Issue #38). Published as unsigned APKs (code 19).
